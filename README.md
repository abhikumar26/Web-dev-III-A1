# Smart Utility Toolkit

## 📌 Overview
The Smart Utility Toolkit is a hands-on lab assignment for **Web Dev III (Node.js & Express Backend)**.  
It demonstrates the fundamentals of backend development using **Node.js core modules** without external packages.

This project includes multiple mini utilities:
- CLI-based calculator
- Custom reusable modules
- Basic HTTP server
- File manager (CRUD operations)
- Random dice generator

---

## 🎯 Learning Objectives
- Execute JavaScript outside the browser using Node.js
- Use `process.argv` for command-line inputs
- Create and reuse custom modules (`module.exports` / `require()`)
- Build a basic HTTP server with routes
- Perform CRUD operations with the `fs` module
- Generate random values securely with the `crypto` module
- Practice modular and reusable coding practices
